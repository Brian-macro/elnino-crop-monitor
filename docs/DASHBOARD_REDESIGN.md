# 简洁中文 Dashboard 改版

> 后续更新：首页“查看历史、价格与预测修正”入口已按用户要求移除；历史复盘功能独立放在导航页。站名、头像、公众号与介绍更新见 [EVENT_STUDY_UPGRADE.md](EVENT_STUDY_UPGRADE.md)。

本轮目标：中文为主、地图首屏、导航去掉品种、前五国家/地区+其他、来源信息渐进披露。保留已有真实数据与历史版本，不增加无来源数字。

布局：单行导航（产量地图/厄尔尼诺/历史复盘/数据说明）；首页短标题与五品种标签；核心白色面板左侧地图、右侧六行榜单；全球产量/同比/前五占比紧靠地图标题。下一层是精简气候状态与产量趋势。具体国家、完整口径和历史版本点击后展开。

配色：暖灰白页面、白面板、墨绿色标题、翡翠绿增产、暖橙减产、浅灰无数据。地图前五有明确颜色，剩余国家按“其他”的汇总变化统一展示；解释清楚不暗示每个剩余国家都同向变化。字体优先系统中文无衬线，数字用tabular-nums，取消大量等宽小字和全大写英文。桌面1440、1024，移动390校验。

“其他”必须由后端按同口径国家集合计算，且与前五互斥、无重叠，可加回全球。地区包含成员时不能把成员再次算进其他。同比由剩余国家的两年合计计算，不平均国家同比。

验证：后端前五/其他求和、同比、成员互斥、缺失处理；中文导航、品种切换、地图可见、详情开关、手机宽度；生产构建及截图检查。

用户已确认：首页全球地图/排行统一采用USDA PSD可比口径，中国详情保留CropWatch、NBS和农业展望。此规则只作用于新的dashboard数据接口，已有独立研究数据源不改动。

界面实现：`Dashboard.tsx`与`SiteNavigation.tsx`；简洁首页复用于`/`、`/map/`及五品种路径。原完整研究组件仅在展开后加载。新增`dashboard_<crop>.json`，单品种约130–190KB，首页不再加载数MB的全量研究记录；中国独立源仅点击中国时请求。

字体：本地WOFF2思源黑体可变字重（约198KB，SIL OFL授权），保留系统字体回退；不依赖访问Google Fonts。地图采用鲜绿色增产、暖橙减产、灰色无数据；南极从地图注册数据中移除。

后端已验证五品种全部年度：前五+其他合计=全球，成员互斥；同比计算剩余成员两年合计，不平均百分比。原始档案和各机构数据库未删除，后台更新入口自动生成轻量dashboard文件。

历史排行按当年的全部有效来源实体选前五，不能被今天的研究短名单限制；因此历史古巴、EU-15等主要产区保留。EU-15与当前欧盟地图成员按历史来源实体分别对应。

最终验证：57个Python测试通过；全量原始数据完整性检查0失败；TypeScript与Next生产构建通过。Playwright在1440、1024、768、390px检查中文四项导航、首屏地图、六行排行、年份/品种切换、中国独立来源、其他成员、按需研究面板和其余导航页面，无运行错误/失败HTTP请求/横向溢出。字体文件包含OFL授权文本。页面已在本地3000和静态3001提供。
