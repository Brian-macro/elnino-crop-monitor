## 日期与定义

研究范围按作物和生产规模筛选，东南亚为固定成员地区，香港/澳门/新加坡等不再进入研究层。海外主序列PSD，中国NBS/CropWatch/农业展望分工；默认不做均值拼接。最新来源方案见 [DATA_STITCHING.md](DATA_STITCHING.md)。原始国家记录继续归档，同义名称规范关联。

- `publication_date` 是明确发布证据；未知则为空。
- `available_date` 控制 as-of。报告仅知月份时保守用月末，并标注假设；未知则用首次获取日。同URL内容改版用首次观察到修订的日期，防止回填。
- 补充日期证据产生 `*.date-evidence-*.json`，原元数据和原始文件保留。新解析版本用内容哈希不同的 `data/vintage` 文件追加保存。
- `calendar_year` 与 `marketing_year`、`paddy` 与 `milled`、`paddy_early`、`winter_wheat` 等严格分组。缺失兼容基准即N/A。
- 中国 Forecast 展示仅来自 CropWatch 与农业展望；源库仍保留其他机构中国数据供证据审计。
