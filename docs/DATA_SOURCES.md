## 日期与定义

研究范围按作物和生产规模筛选，东南亚为固定成员地区，香港/澳门/新加坡等不再进入研究层。有本国预测数据用本国预测数据，无则用 PSD；历史基础库保留 PSD 修订估计，默认不做多机构均值。最新来源方案见 [DATA_STITCHING.md](DATA_STITCHING.md)。原始国家记录继续归档，同义名称规范关联。

- `publication_date` 是明确发布证据；未知则为空。
- `available_date` 控制 as-of。报告仅知月份时保守用月末，并标注假设；未知则用首次获取日。同URL内容改版用首次观察到修订的日期，防止回填。
- 补充日期证据产生 `*.date-evidence-*.json`，原元数据和原始文件保留。新解析版本用内容哈希不同的 `data/vintage` 文件追加保存。
- `calendar_year` 与 `marketing_year`、`paddy` 与 `milled`、`paddy_early`、`winter_wheat` 等严格分组。缺失兼容基准即N/A。
- 中国玉米、大豆、糖优先配置 CASDE，小麦配置 CropWatch；水稻 CropWatch 为稻谷，精米转换未通过验证时使用 PSD 精米。NBS Actual、农业展望长期预测与各机构原始序列独立保存。
- 本土同比只用同源相邻年、相同产品定义和已验证年度映射；不使用本土本年值除以 PSD 上年值。
- NOAA 是独立气候观测来源，农业产量 Forecast 不是气候预测。预测来源每日北京时间 14:17 检查；历史产量、气候与价格基础库手动维护。
