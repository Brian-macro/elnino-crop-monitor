# 地区优先的数据后端重构

用户要求：地区作为研究单元；剔除非生产者与无意义作物；主来源明确；历史、预测拼接有合同；自动更新简单。沿用真实归档和数据表，不重抓已完成原始数据。

## 最终结构

`config/research_policy.json` 是研究范围、固定作物成员、主来源与调度的单一配置。`scripts/policy.py` 读取并检查配置。`scripts/regions.py` 按同一来源、同一原始快照、固定成员汇总地区。`research.py` 只编排规范化、地区汇总、研究范围过滤与输出。`outlook.py` 统一来源和比较；前端读取后端指定来源，不维护第二份机构顺序。

海外主数据库为USDA PSD，覆盖历史估计和前瞻预测，WASDE作为月度版本对照。东南亚成员按作物冻结：5年历史平均产量筛选小麦/玉米/水稻至少0.5 Mt，大豆至少0.1 Mt，糖至少0.25 Mt；明确为产品筛选门槛而非统计事实。使用2020–2024的PSD已存快照计算，生成明确成员名单，不随每日更新自动漂移。香港、澳门、新加坡、文莱、东帝汶排除出研究层；原始数据仍归档。

中国是独立研究单元，短期CropWatch、长期农业展望、Actual用NBS。NBS/CropWatch自然年与PSD市场年不强拼。历史参考PSD单独标注；不假造中国长期Actual序列。中国和海外源的水稻稻谷/精米定义不混合。

地区总量对固定成员求和，要求同一document、年度、口径、状态齐全；缺成员时整个该快照缺失，不能缩小样本继续给总量。成员证据、政策版本、报告日期、成员数随地区记录输出。地区单产在同口径下由产量/面积计算，水稻精米产量不能除以粗稻面积当稻谷单产。历史与预测成员始终一致。地区总量不得再计入Global总量。
