# 本土来源跨页面一致性验收

当前原则：有本国预测数据用本国预测数据，无则用PSD。

## 已修复

- 首页、历史复盘共用同一产量组合，输出本土来源、原始链接、可得日期与回退原因。中国详情复用同一选择。
- 数据说明及公开政策矩阵按国家/作物登记来源，修复中国玉米、大豆、糖仍写CropWatch的旧口径。
- 删除静态详情与production API中排除CASDE的旧中国预测白名单；保留全部原始来源用于核查。
- 本土产量不混接USDA库存、消费。PSD/WASDE供需参考独立选择；历史修订值不伪装事件当时可得预测。
- 气候页按ONI实际连续暖季确定末端暖段，跨年不重置，缺月中断；1/3月变化按准确日历月。NOAA基础观测手动维护。
- 本机旧全量定时任务停用，失效更新锁经无进程持有检查后清除。已有本机抓取原始归档保留。
- 来源矩阵生成器独立写SOURCE_MATRIX.md，避免覆盖已审定方法。
